# 域名 lingluo-toki.top 上线部署步骤

服务器：阿里云 Ubuntu 22.04，公网 IP `101.132.104.41`，应用监听 `127.0.0.1:8000`
域名解析已确认：`lingluo-toki.top` → `101.132.104.41`（阿里 DNS / 腾讯 DNS 均已生效）
备案号：赣ICP备2026025888号-1

## 第 0 步：前置检查（必做）

```bash
# 1) 确认 nginx 已安装并查看现有配置（避免与新配置冲突）
nginx -v
ls /etc/nginx/conf.d/ /etc/nginx/sites-enabled/ 2>/dev/null
grep -rl "server_name" /etc/nginx/conf.d/ /etc/nginx/sites-enabled/ 2>/dev/null

# 2) 确认应用本身正常
curl -s http://127.0.0.1:8000/api/health; echo

# 3) 确认 80 / 443 端口监听情况
ss -tlnp | grep -E ':80|:443|:8000'
```

> **关键：阿里云安全组必须放行 443 端口。**到阿里云控制台 → 轻量应用服务器 → 防火墙，
> 添加「HTTPS / TCP / 443」。只放行 80 不放行 443 会导致 HTTPS 完全打不开。
> 同理确认 80 端口已放行（证书签发与续期都依赖它）。

## 第 1 步：放置 HTTP 配置并签发证书

```bash
# 备份现有配置
mkdir -p /root/nginx-backup-$(date +%Y%m%d)
cp -a /etc/nginx/conf.d /root/nginx-backup-$(date +%Y%m%d)/ 2>/dev/null
cp -a /etc/nginx/sites-enabled /root/nginx-backup-$(date +%Y%m%d)/ 2>/dev/null

# 写入阶段一配置（HTTP 版，仅用于签发证书）
cat > /etc/nginx/conf.d/eye-diagnosis.conf <<'EOF'
server {
    listen 80;
    listen [::]:80;
    server_name lingluo-toki.top www.lingluo-toki.top;

    location /.well-known/acme-challenge/ {
        root /var/www/html;
        default_type "text/plain";
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

# 创建验证目录（certbot webroot 模式需要）
mkdir -p /var/www/html/.well-known/acme-challenge

# 测试并重载
nginx -t && systemctl reload nginx
```

**若 `nginx -t` 报 server_name 冲突**：说明 sites-enabled/default 已占用，
先改名禁用：`mv /etc/nginx/sites-enabled/default /etc/nginx/sites-enabled/default.disabled`
（注意：先确认它不是当前在用的站点配置）。

**签发证书：**

```bash
# 安装 certbot（Ubuntu 22.04 自带源即可）
apt-get update -y && apt-get install -y certbot

# 签发（webroot 模式，nginx 不需要停机）
certbot certonly --webroot -w /var/www/html \
  -d lingluo-toki.top -d www.lingluo-toki.top \
  --agree-tos -m 你的邮箱@example.com --no-eff-email

# 确认证书文件存在
ls -l /etc/letsencrypt/live/lingluo-toki.top/
```

> 若更想用**阿里云免费 SSL 证书**：到阿里云控制台申请（选 nginx 版下载），
> 得到 `.pem`（证书链）与 `.key`（私钥），上传到 `/etc/nginx/cert/`，
> 然后在阶段二配置里改用阿里云那两行路径即可。缺点是 3 个月需手动续期，
> 而 certbot 默认已配置定时器自动续期。

## 第 3 步：前端页面加 ICP 备案号

前端已在 `src/server/static/index.html` 底部新增备案行（版本 v2026-10-15.27）。

已推送至 GitHub，远端提交 **`2070d5f`**（内容与本地一致）。

**方式 A-1（推荐）**——GitHub API 通道。仓库为 public，**无需 token**，且不受
`raw.githubusercontent.com` 被墙影响（服务器实测该域名不可达，但 `api.github.com` 可达）：

```bash
curl -fL --connect-timeout 15 --max-time 90 \
  -H "Accept: application/vnd.github.raw" \
  -o /opt/eye-diagnosis/src/server/static/index.html \
  "https://api.github.com/repos/lingluoTOKI/Intelligent_diagnosis_system/contents/src/server/static/index.html?ref=2070d5fb0ae0a8d5690ac9ded0616165cdce213d"

# 校验拉取结果（应为 137965 字节，且能搜到备案号）
wc -c < /opt/eye-diagnosis/src/server/static/index.html
grep -c "赣ICP备2026025888号-1" /opt/eye-diagnosis/src/server/static/index.html
grep -o "v2026-10-15.27" /opt/eye-diagnosis/src/server/static/index.html | head -1

systemctl restart eye-diagnosis
```

**方式 A-2（备选）**——jsDelivr CDN（服务器上此前实测可用）：

```bash
curl -fL --connect-timeout 15 --max-time 90 \
  -o /opt/eye-diagnosis/src/server/static/index.html \
  https://cdn.jsdelivr.net/gh/lingluoTOKI/Intelligent_diagnosis_system@2070d5fb0ae0a8d5690ac9ded0616165cdce213d/src/server/static/index.html
systemctl restart eye-diagnosis
```

> 使用完整 commit 号（而非 `@main`）可避开 CDN 缓存，确保拿到刚才这一版。
> **重启 eye-diagnosis 需要 1~2 分钟**（重新加载 ONNX 模型），不要 Ctrl+C 打断。

**方式 B（无需推送）**——直接在服务器上插入备案行：

```bash
python3 - <<'PY'
p='/opt/eye-diagnosis/src/server/static/index.html'
s=open(p,encoding='utf-8').read()
css='.icp-line{margin-top:8px;text-align:center;font-size:var(--fs-small);color:var(--muted);line-height:1.6}\n.icp-line a{color:var(--muted);text-decoration:none}\n.icp-line a:hover{color:#7fb3ff;text-decoration:underline}\n'
old='  <div class="statusbar">'
assert old in s and 'icp-line' not in s
s=s.replace(old, css.rstrip('\n')+'\n'+old, 1)   # CSS 落在 style 之后即可，位置不敏感
old2='''  <div class="statusbar">
    <span id="barLeft">服务端部署入口 · ONNX Runtime</span>'''
if old2 in s:
    s=s.replace(old2, old2, 1)
# 在 statusbar 之后插入备案行
import re
m=re.search(r'(</div>\s*\n)(\s*<div class="statusbar">.*?</div>\s*\n)', s, re.S)
if m:
    s=s[:m.end(2)]+'  <div class="icp-line">\n    <a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener">赣ICP备2026025888号-1</a>\n    <span> · 输出结果不构成医学诊断依据，仅供教学与科研演示使用</span>\n  </div>\n'+s[m.end(2):]
open(p,'w',encoding='utf-8').write(s)
print('已插入备案号')
PY
systemctl restart eye-diagnosis
```

> 注意：重启 Eye 服务需要 1~2 分钟（要重新加载 ONNX 模型），**不要 Ctrl+C 打断**。
