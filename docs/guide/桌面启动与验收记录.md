# 桌面启动与验收记录（2026-10-13）

## 启动
双击项目根目录“启动系统.cmd”。使用 D:/Anaconda3/envs/yolov10/python.exe，不需要 conda activate。启动器先检查 PyQt5、OpenCV、NumPy、Torch，随后启动 visualization_test2.py。运行时保留启动终端，请勿关闭该终端；正常退出系统后终端自动关闭，启动失败则停留显示错误。日志位于 runtime/startup_logs，每次独立命名。换电脑须安装依赖并设置 EYE_PYTHON，同时校正模型和框架路径。本入口启动现有桌面系统，不额外启动训练或开发板脚本。

只检查环境：python scripts/launch_desktop.py --check。

## 偏好
系统设置 → 界面显示可调整字体、界面字号和固定图像目录。阅读字号与自动朗读即时保存；正常关闭时保存窗口尺寸、位置和单图分栏比例。恢复界面默认设置恢复微软雅黑14、阅读14、关闭自动朗读、默认比例并最大化，不清除历史记录、API密钥或固定图像目录。偏好文件 configs/ui_preferences.json。

## 本轮验证
自动测试覆盖分类失败不写成功记录、模型加载失败、异常图像、API异常模拟、会话归属、批量保存失败口径、历史过滤、导出、阅读字号和偏好恢复。
真实 GPU 流程使用隔离测试库：加载当前配置权重并分类 data/val/N/105_right.jpg，结果 Normal，设备 RTX 4060 Laptop，模型加载约6.5秒。这是一次本机测量，不是保证启动速度，也不是准确率实验。

## 未实机验收
摄像头拍摄、麦克风识别、实际扬声器出声、开发板连接、真实断网恢复、全新环境安装尚需人工验收。在线问答异常采用模拟验证，本轮未发送真实 API 请求。此前已验证 Edge TTS 可生成 MP3，不能据此断言音频设备播放正常。

## 人工验收步骤
1. 双击启动，确认主窗口出现、模型就绪。
2. 选择图像并分类，生成建议、多轮问答；切换阅读字号。
3. 批量处理含损坏图像的样例，确认错误条目有原因，成功条目可查询、导出。
4. 在历史页按日期查询，检查导出范围。
5. 选择本机摄像头拍照；测试语音输入及朗读/停止。
6. 修改阅读字号、自动朗读、分栏和窗口大小，正常退出后重开确认恢复。
