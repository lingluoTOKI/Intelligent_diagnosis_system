## 〇、通用规格（每张图都适用，生成前先读这一节）

**画幅与背景**

- 横版 16:9，建议 2560×1440 及以上，导出 PNG
- 纯白背景（#FFFFFF），不要任何纹理、网格、纸质质感

**风格**

- 扁平矢量示意图，细描边（1–1.5 px），圆角矩形
- 禁止：渐变、阴影、投影、3D 立体、发光、拟物化、装饰花纹、水印、logo、边框外框
- 层级靠"分区 + 留白 + 箭头"表达，不靠颜色堆叠

**文字**

- 字体：思源黑体或微软雅黑类无衬线字体，字重清晰
- **所有中文标签必须完整、准确、无错字、无缺字、无乱码**
- 文字不得重叠、不得被框线裁切、不得超出画布
- 同一层级字号一致；主标签比副标签大 1–2 pt

**统一配色（5 张图必须一致，否则报告风格会花）**

| 用途        | 填充色     | 描边色     | 文字色     |
| --------- | ------- | ------- | ------- |
| 交互层 / 前端  | #DCE9F7 | #5B7DA6 | #1F2A37 |
| 应用层 / 服务层 | #DCEDE0 | #4E8A63 | #1F2A37 |
| 数据层 / 存储  | #E5E0F3 | #7A6BA8 | #1F2A37 |
| 外部服务 / 强调 | #FDEBD8 | #D39B4A | #6B4410 |
| 警示 / 异常分支 | #FBE3E3 | #C0504D | #7A2A2A |

箭头：细线 #8A93A0，箭头头部为开放式细三角，不要实心粗箭头。

## 六、以下 4 张图不要交给 AI 生成

实验分析报告的这 4 张图是**数据图表**，图上每个数字都来自真实实验结果，扩散类生成模型会编造数值且不易察觉，属于学术诚信风险：

| 图号    | 图名                 | 为什么不能用 AI 生成                              |
| ----- | ------------------ | ----------------------------------------- |
| 实验 图1 | 数据集类别分布            | 八类真实计数（正常 2298、糖尿病视网膜病变 1286…）            |
| 实验 图2 | 历史训练曲线（2×2 四组对照）   | 真实 loss / top-1 序列，含 140 重复样本的记录          |
| 实验 图3 | 四组实验混淆矩阵对照         | 真实混淆矩阵数值                                  |
| 实验 图4 | 准确率 / 参数量 / 训练成本对比 | 63.285%、63.199%、1,541,352、1,487,772 等精确数值 |

如果你希望这 4 张更好看，正确做法是**告诉我，我用代码重画**（换配色、换版式、加参考线），数值与坐标轴保持真实。

## 七、如果你的 GPT 支持"生成代码画图"

若模型能直接输出绘图代码（如 Python + matplotlib），把上面每节的完整提示词末尾追加一句：

```
请改用 Python matplotlib 绘制这张图，中文用微软雅黑（Microsoft YaHei），
输出可运行代码并保存为 200 dpi 的 PNG。所有文字与数字必须准确无误。
```

代码路线的文字准确率远高于直接生成图片，且便于你后续微调。
