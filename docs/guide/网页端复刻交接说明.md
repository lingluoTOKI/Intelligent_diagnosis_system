## 二、给下一棒的关键技术事实（别踩坑）

1. **实际推理输入是 512，不是 224。** `best.pt` 权重自带 `Resize(512)+CenterCrop(512)`，
   Ultralytics 优先用权重自带 transforms 并忽略 `imgsz`，`configs` 里的 `image_size:224` 从未生效。
   服务端必须用 `models/server/best512.onnx`。按 224 导出会与桌面端不一致（20 张样本仅 5 张 Top-1 相同）。
2. **模型是 YOLOv8n-cls**，30 层，1,445,128 参数，3.3 GFLOPs，**AKConv 层数 0**。
   目录名 `AKConv_best_moudle` 不代表权重含 AKConv，报告不得据此宣称。
3. **桌面端视觉规范的真正出处**不是 `visualization_test2.py` 里的旧 QSS（会被覆盖），
   而是 `src/visualization/workbench_theme.py`（配色）+ `workbench_layout.py`（布局结构）。
4. **字号是 pt 不是 px**：Qt 样式表 14pt ≈ 18.7px。网页端正文必须写 18px，写 14px 会明显偏小。
5. **结果文案有两套中文名**：摘要用全名（年龄相关性黄斑变性），概率面板用简称（黄斑变性）。
   分数格式 `.1%`，推理耗时显示「本次推理 0.20s」，概率按概率降序排列。
6. **禁止编造结果**：分类失败不得返回默认疾病或占位置信度；禁止 AMD/0.98 这类占位数据。
7. **数据集存在泄漏（最高优先级未完成项）**：`data/train` 与 `data/val` 有 140 个相同哈希，
   未按患者划分。旧实验指标全部作废，必须去重 + 按患者重划分后重训重测，报告数字只能来自重跑。
8. **报告用延迟必须取服务器实测 192–204 ms**，不得引用本机 53 ms。

### 3. 客户端与服务端的能力边界（v2026-10-13.8 已修正分类口径）

判断"网页端能不能做"时，必须区分三个层面，混为一谈会得出错误结论：

| 层面 | 事实 | 网页端结论 |
|---|---|---|
| 服务器进程 | 跑在阿里云，没有摄像头、没有声卡、没有用户本地磁盘 | 服务器进程本身确实做不到 |
| 浏览器（用户电脑） | 页面运行在用户机器上，`getUserMedia` 能直接开用户本机摄像头；下载的文件直接落到用户本地磁盘 | **基本都能做到** |
| 局域网硬件 | 开发板通过 UDP 5002 向本机推流，公网浏览器无法接收局域网内硬件的视频流 | **真正做不到** |

按此口径：

- **本机摄像头**：已实现（浏览器直接调用户电脑的摄像头，见上文追加项 1）。
- **完整导出包**：已实现，全部落在用户电脑本地（见上文追加项 2）。
- **开发板摄像头**：保留与桌面端一致的占位说明，硬件演示请用桌面客户端。
- **语音输入与自动朗读**：**已实现（v2026-10-13.20）**。输入走浏览器
  Web Speech API，需 Chromium 内核且要求 HTTPS 或 localhost。朗读优先调用服务端
  `POST /api/tts`，用 `edge-tts` 生成晓晓自然音色 MP3 并按文本、语言和语速缓存；
  生成失败时自动降级到 `speechSynthesis`。音频在页面内播放，不弹出外部播放器。
  设置页「语音能力」区块会实时显示当前浏览器的支持情况与可用语音包数量。
- **字号偏好持久化**：**已实现（v2026-10-13.16）**。界面字号（小/标准/大/特大）、
  阅读字号、朗读语速与语言、自动朗读开关写入 localStorage（键 `eye.prefs.v1`）。
  界面字号通过改写 `html` 元素的内联 CSS 变量生效——内联优先级高于媒体查询，
  因此用户在窄屏上的显式选择不会被响应式降级覆盖。
  注意：偏好只存本机，不上传服务器，换设备需重新设置（这与桌面端写
  `configs/ui_preferences.json` 的行为一致，都是本机持久化）。
- **批量批次号 `batch_id`**：**已实现（v2026-10-13.16）**。服务端每次「开始分类」
  生成可读批次号 `B<日期时间>-<4位随机>`，写入 `records.batch_id` 并登记到
  `batches` / `batch_items` 表；新增 `GET /api/batches` 与 `GET /api/batches/{id}`；
  历史页可按批次筛选，表格里的批次标签可点击直达。「重试失败项」属新一次提交，
  会生成新批次号。整批删除未做（服务端暂无该接口）。
