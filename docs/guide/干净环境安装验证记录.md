## 建议的正式复核步骤

1. 在新的 Windows 虚拟环境或空白 Python 环境中创建虚拟环境。
2. 安装 `requirements-core.txt`、`requirements-pc.txt` 和按需 `requirements-voice.txt`。
3. 保留 `models/`，但不要复制 `data/`、`runtime/`、密钥文件和个人配置。
4. 运行 `启动系统.cmd`，加载模型，使用仓库提供的非敏感样例图或现场图像完成一次分类。
5. 记录 Python 版本、显卡/CPU、安装耗时、首次缺失依赖、解决办法和截图。
6. 服务器侧按 `docs/guide/服务器部署说明.md` 在隔离目录部署，再调用 `/api/health`、单图、批量、历史和朗读接口。

## 结论

本项目已有隔离环境中的模型级验证和自动化测试，但“从零完整安装”尚未作为独立验收完成。课程材料据此如实记录，避免把局部验证扩大为完整安装通过。
