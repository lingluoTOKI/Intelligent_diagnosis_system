## 事实基线与不得改写的限制

1. 历史资料指向 ODIR 数据集及天池页面 `94998`；原始标签表、标签转换规则、患者级划分规则尚未找到可复核证据。
2. 当前目录审计得到训练集 5110 张、验证集 1163 张；两集合有 **140 个跨集合完全相同的 SHA-256 内容哈希**。现有验证指标只能作为受污染划分上的历史观察，不能写成独立泛化性能。
3. 归档训练日志显示 `imgsz=224`；当前服务器 ONNX 推理输入为 512。报告中已分开描述，不能把两者当作同一实验设置。
4. 当前部署权重为原生 YOLO11n-cls，AKConv 实际层数为 0。AKConv 对比日志仅作为历史框架实验记录，不能宣称已进入线上模型。
5. 本机逻辑测试历史结果为 52 项通过；模型加载与单张 ONNX 分类已在隔离环境完成过验证。开发板没有实机设备，因此只可标记为“未实机验收”。
6. 服务器已部署并由操作者报告 systemd 服务为 active；对外域名、反向代理及浏览器端端到端验收仍应在提交前按部署说明复核一次。

## 提交前最后人工核验

- [ ] 打开桌面端，完成一次本地图片分类并保存截图。
- [ ] 批量导入至少两张图片，导出 CSV；在历史记录页检索并导出。
- [ ] 用本机摄像头拍照后完成一次分类。
- [ ] 用麦克风进行一次语音输入；确认识别文字可编辑。
- [ ] 点击朗读，确认应用内播放 MP3；首次生成可能受网络影响，再次相同文本应命中缓存。
- [ ] 在服务器地址完成一次单图、批量、历史记录和朗读测试，并保存时间与截图。
- [ ] 若无开发板，在验收表写“未实机验收”，不要勾选通过。
- [ ] 确认最终 ZIP 不含 `data/`、本地运行时目录、密钥文件与个人临时文件。
