# PC运行与测试说明

PC版提供本地图像八类分类、DeepSeek辅助问答和SQLite历史记录。语音和开发板通信为可选扩展，默认关闭；没有树莓派也可以运行PC版。

## 本机环境

GUI与系统测试使用 `D:\Anaconda3\envs\yolov10\python.exe`。本机版本为Python 3.9、PyTorch 2.5.1+cu118、TorchVision 0.20.1+cu118、NumPy 1.26.4及PyQt5 5.15.11。

实验Notebook调用 `D:\Anaconda3\envs\yolo26\python.exe`。它是独立的训练环境，PC依赖安装不需要在这个环境中执行。

现有环境直接启动：

```powershell
Set-Location 'C:\Users\47449\Desktop\yolo\Intelligent_diagnosis_system'
& 'D:\Anaconda3\envs\yolov10\python.exe' visualization_test2.py
```

没有系统登录账号。在线问答需要用户自己的DeepSeek API密钥；无密钥时分类和历史记录仍可使用。

## 新PC环境安装

使用Python 3.9至3.12，在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
```

`requirements.txt`引用PC依赖，PC依赖再引用核心依赖。核心依赖以editable方式安装项目内的 `ultralytics-main`，避免混用另一个已安装版本。依赖文件不包含Python解释器本身。

GPU环境需要匹配的PyTorch与TorchVision CUDA轮子。此处以本机已验证的2.5.1/0.20.1组合为基准；本次验证使用现有环境，尚未在全新环境重新安装全部依赖。

语音可选安装：

```powershell
python -m pip install -r requirements-voice.txt
```

安装后还需要麦克风、音频权限，以及可选Vosk中文模型；在运行设置中启用语音。`requirements-board.txt`仅用于可选硬件/ONNX和投屏，不属于PC默认安装。树莓派上的picamera2/libcamera使用系统包。

## 运行与网络设置

打开菜单“设置 → 运行与网络设置”，可以修改：

- 默认分类权重和Ultralytics源码目录；选择YOLO26实验权重时应匹配相应框架。
- 设备：`auto`自动选择CUDA或CPU，`cpu`强制CPU，`0`表示CUDA中的第一个GPU，不是Windows任务管理器的显示编号。
- 是否启用语音或开发板通信。
- 自动选择局域网IP、优先网卡，或者关闭自动识别后手动填写IPv4。

自动识别只考虑活动的局域网接口，排除已识别的代理、VMware、Hyper-V、VPN和环回接口，不通过连接外网探测地址。当前设备的Meta Tunnel为198.18.0.1，WLAN为192.168.1.101。网络切换后地址可能变化；离线时自动模式返回127.0.0.1。

应用运行设置写入 `configs/app_config.json`，网络设置写入 `configs/system_config.json`，保存后重启生效。`configs/system_config.py`读取统一网络文件，不再维护另一份PC地址。

以下环境变量优先于应用配置文件：`EYE_APP_CONFIG`、`EYE_MODEL_PATH`、`EYE_FRAMEWORK_PATH`、`EYE_DEVICE`、`EYE_HISTORY_DB`。DeepSeek密钥也可以通过 `DEEPSEEK_API_KEY`提供。旧的 `saved_api_key.txt`兼容保留，Base64只是编码，不是加密；该文件不进入提交包。

## 操作流程和失败行为

1. 启动时自动加载配置的权重；不存在时提示用户手动选择。状态栏显示实际权重、分类任务和设备，鼠标悬停可查看框架版本、路径、类别和AKConv层数。
2. 加载本地图像并进行分类。只有有效的八类概率输出才可展示、保存历史和生成当前报告。
3. 模型加载、推理或解析失败时清空当前结果，禁用结果与报告按钮，不返回“AMD、0.98”等固定结果。失败切换模型也不会继续使用旧模型。
4. API断网、超时或响应无效时明确显示失败。分类辅助建议的本地资料标注为“本地参考资料，非DeepSeek在线回答”，不会缓存为成功的在线回答。
5. 在线多轮问答只保留最近六个成功轮次。API失败不写入成功会话上下文。辅助建议在后台请求，返回时核对当前分类状态；切换图像或分类失败后，旧回复不会覆盖当前界面。
6. SQLite默认位于用户目录的 `EyeDiseaseDetectorHistory/history.db`，图像副本位于配置的image_dir。原历史数据保持不动，新失败结果不入库。旧历史记录不能作为模型实验的性能证据。
7. 趋势演示数据明确使用 `[演示]`标签，只用于界面演示，不属于真实病例或课程实验。

## 无GUI检查

下面的命令不调用DeepSeek，也不写历史记录：

```powershell
python scripts/check_pc_runtime.py
python scripts/check_pc_runtime.py --image '一张实际图像的路径.jpg' --device cpu
```

输出包括实际框架、类别、AKConv层数和局域网接口。退出码0表示检查成功，1表示模型加载失败，2表示图像分类失败。

## 自动测试

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests/test_application_services.py tests/test_gui_classification.py -q
```

测试覆盖缺失/错误权重、异常图像、错误概率、类别映射、API断网和认证失败、会话记忆、历史查询、GUI失败后的状态清空、批量失败不入库，以及网络自动/手动设置。API测试使用注入的测试客户端，不调用真实API、不消耗余额。GUI测试使用offscreen显示，不写用户的真实历史数据库。

麦克风、真实在线API、多设备通信和树莓派实机尚未由这些测试验证。课程验收需要另记录实际功能演示；任务书中的服务器部署是否接受PC服务端仍需落实。


## 图像工作台与后台任务（2026-10-12）

主界面采用深蓝布局：左侧导航、中间单图预览、右侧分类概率与辅助问答。图像可通过按钮导入、双击画布选择或拖入；窗口缩放时保持图像比例。右侧只展示实际分类输出，全部八类概率通过“查看全部8类概率”打开。分类完成后不自动弹窗或调用在线API，点击“生成说明”获取辅助参考。

模型加载、图像解码、分类推理、图像保存、批量分类和API连接测试在后台执行。进行计算时暂停冲突操作；取消在当前步骤完成后生效，不强制中断CUDA计算。关闭窗口时等待后台任务安全结束。缩略预览最长边为1600像素，仅影响屏幕显示，模型使用原始解码图像。

本次改动前的逐文件备份位于 `backups/before_ui_performance_20261012_214906/`，包含清单。早期重建的旧界面另行保留。


## 原版布局的显示改进（2026-10-13）

界面恢复为原版的左右分区：左侧约30%为本地图像/摄像头及操作按钮，右侧约70%为分类结果、八类概率、辅助建议/多轮问答/系统设置。小窗口会优先保证控件的最小可读宽度，分割线可拖动。历史记录、趋势统计、开发板交互、板端语音及语音输入继续使用原功能入口；未启用的可选功能保留入口并禁用。

右上角“界面字号”提供14、16、18磅三档，即时生效，保存在configs/ui_preferences.json。设置区域支持滚动；历史与结果等对话框统一采用深蓝样式。查看结果直接定位右侧八类概率，避免重复弹出结果窗口。后台加载、分类和取消功能继续保留。


### 系统设置与启动响应（2026-10-13）

主界面右侧「系统设置」现在提供局域网配置：自动识别活动物理网卡、优先网卡、本机 IPv4、开发板 IPv4 和当前端口。模型路径、框架路径、设备与可选语音/开发板开关收纳在「展开模型与语音 / 开发板开关」中。保存后重启，保证已经启动的网络监听器和模型使用同一份配置。顶部「设置 → 运行与网络设置」仍可用。

启动时不再提前导入统计绘图库，连接配置表单在首次打开设置页时构建；分类模型继续后台加载。图形界面可见与模型就绪是两个不同阶段，首次模型加载和 CUDA 初始化仍需要时间。麦克风测试在后台进行，成功仅证明设备能访问并完成噪声采样，不代表真实识别质量已验收。

网络地址保存经过 IPv4 校验；板端语音唤醒/音频发送读取保存的开发板地址，不再使用原来的硬编码地址。UDP 指令发送成功不代表开发板收到或已执行；真实设备通信、语音识别与新环境安装仍需单独验收。


### 完整功能分页（2026-10-13）

主窗口分为「单图分析」「批量分析」「历史记录」。分类结果在单图页自动显示，不再提供重复的「查看结果」按钮。批量页选择图像后启动任务，持续显示每张图像的结果或失败原因，并可导出任务明细 CSV；取消后已完成记录保留。任务进度和取消按钮放在页面下方，切换页签仍可操作。历史页按需构建，支持分页、刷新、详情、统计及确认后删除。

所有网络、模型、DeepSeek 与语音设置统一在顶部「设置 → 系统设置」窗口；主界面不再另设系统设置页签。网络和模型配置保存后重启生效。


### 统一工作台改造（2026-10-13，当前版本）

本节取代上文旧版分页、统计弹窗和密钥保存描述。

- 批量页先添加图像或文件夹、检查列表，再开始分类。主页面直接提供结果表、分类分布、筛选和详情；支持取消、移除、失败重试、恢复最近200个已保存批次。重试会建立新批次。分类成功与历史保存失败分别统计。
- 批次及逐项状态保存在原SQLite数据库的新表，原记录追加完整概率、模型信息、批次字段。首次升级旧表前生成 `.before_batches.bak` 备份。旧记录缺失的概率和模型来源不会补造。
- 新批量成功图像复制到配置的图像目录，历史详情不再仅依赖原文件路径。旧记录路径保持不变。
- 历史页按日期、类别、文件路径和批次筛选，100条分页。查询与统计在后台执行，类别图和每日趋势随相同筛选条件变化；标注为演示的记录排除在此页统计之外。
- 统一“导出当前范围”在后台生成结果明细CSV、统计CSV、分布PNG/PDF、PDF报告和范围JSON；历史另有每日趋势图。可打开导出目录。导出重新读取相同历史筛选条件的数据库快照，期间新增的记录可能被包含。
- 会话发送时固定问题、图像上下文和会话编号，防止旧回复覆盖新会话；换图、切模型或清空会话会创建新上下文。清空会话不删除辅助建议。发送期间防止重复发送；关闭后忽略未完成回复。
- 设置窗口分为运行与网络、DeepSeek、外设页。模型/网络/功能开关保存后重启，API密钥保存后立即使用。Windows重新保存密钥时使用当前用户DPAPI保护，兼容读取旧编码文件；没有自动改写用户现有密钥。非Windows请使用环境变量。
- 顶部提供等线、思源黑体、微软雅黑（仅列出本机可用字体）以及14/16/18字号，立即生效并记住偏好。默认等线。小窗口大字号时单图页可滚动，概率详情可折叠。

本轮验证使用隔离测试数据库，含旧表升级、筛选口径、批次持久化、保存失败、旧回复隔离和导出文件验证。1.5万条合成记录查询与聚合一次约0.031秒（单次本机测试，非生产性能承诺）。实际RTX4060分类验证成功；一次冷模型加载约23.6秒，界面定时器持续响应。1366×768和1920×1080离屏截图、125%/150%缩放以及14/18字号已检查。真实语音、开发板通信、全新环境安装及服务器部署仍需单独验收。
